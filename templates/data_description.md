# Adapter 数据说明

填写后放在 adapter 目录，并随对应 bag 交付；不适用项填“无”，已有文档可直接引用。

- 机器人型号、adapter 版本、对应 bag：
- 各 topic 的数据来源、源采样频率和发布频率：
- 全局位姿：坐标系、原点、轴方向、本体参考点：
- IMU：各轴方向、角速度正方向、是否去除重力：
- 速度指令：坐标系、轴方向：
- 雷达／相机：设备 ID、坐标系；已有安装或标定文件位置（如有）：
- 时间戳：采样时间还是接收时间，设备时间如何换算、跨主机如何同步（如适用）：
- 关节：名称与实际关节的对应；effort 来源（实测／估算／指令，如有）：
- 选填状态：nav_state、motion_state、manipulation_state 是否提供、各数字的含义：
- 整体模式扩展：robot_state.state 使用 4–255 时，各数字的含义（无则填“无”）：
- 其他状态量（含物理按键／开关对应的模式、功能状态）：status_names 各项含义及 status_values 数字含义；无法获取的状态注明，无适用项填“无”：
